# OtaWatt
OtaWatt est un logiciel Windows léger et open source créé par OtaFox pour surveiller en temps réel la consommation électrique d’une prise Shelly. Il affiche puissance, tension, intensité, fréquence, température et état de santé pour les Gamer et l'overclocking, avec enregistrement CSV, mode compact et démarrage automatique optionnel.
